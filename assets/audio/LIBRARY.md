# Sound library — Silicon Valley origin doc (taiwan-edit)

All files: **48 kHz, 24-bit PCM WAV**. Generated by the scripts in `tools/audio/`
(re-runnable, fixed seeds → identical output). How to use them in the mix: `MIX_RULES.md`.

## Regenerate

```bash
bash setup.sh   (creates .venv with numpy scipy pillow soundfile)
PY=.venv/bin/python
$PY tools/audio/gen_music.py        # all cues  (or: gen_music.py curious|historic|tension|momentum|resolve|stingers)
$PY tools/audio/gen_sfx.py          # synthesized SFX
$PY tools/audio/import_kenney.py    # CC0 Kenney picks -> sfx/kenney_*.wav (needs _raw/ extracted)
$PY tools/audio/analyze.py          # 'listen' by numbers: peak, LUFS, band balance, loop seams
$PY tools/audio/build_bed.py sheet.json out.wav   # stitch cues/stems into one bed (Phase 2)
$PY tools/audio/place_sound.py      # Phase 2: place everything on the 600 s edit -> bed/*.wav + timeline.json (~2-3 min)
$PY tools/audio/measure_mix.py      # test mix VO + beds -> renders/testmix_600s.wav + measurements
$PY tools/audio/build_library.py    # rewrite this file
```

Scripts: `dsp.py` (filters, reverb, noise shaping, loop tools), `instruments.py` (marimba / pizz / pad / boom),
`loudness.py` (BS.1770 LUFS), `_manifests/*.json` (the metadata this file is built from).

## Music cues

One key family: **D major** (default) / **B minor** (relative minor, tension) / **G major** (IV, nostalgia)
— any cue can crossfade into any other over ~2 s. Every cue folder has `_FULL.wav` plus
`_stem_marimba / _stem_pizz / _stem_pad` (stingers also `_stem_low`). Stems are rendered at the
**same gain** as FULL, so `marimba + pizz + pad (+ low) == FULL` — drop stems to thin the bed under
dense narration (e.g. marimba+pad only, or pad only), add them back in gaps.

Library level: FULL mixes are normalized to **−18 LUFS-I**, true peak ≤ −1 dBFS. That is a *storage*
level — under the VO they sit at ~−29 to −31 LUFS (see MIX_RULES.md, data-volume ≈ 0.28–0.35).

Voice pocket baked in: every music file has a static EQ (high-pass 38 Hz, −2 dB @1.3 kHz, −4.5 dB @2.8 kHz,
+4 dB high shelf above 6 kHz). Measured share of energy in the 1–4 kHz band: music −17 to −24 dB
re total vs the narrator's −7 dB — the marimba's fundamentals (250 Hz–1.2 kHz) and its mallet
'tick' (5–11 kHz) carry it; its 1–4 kHz overtones are deliberately tamed. The dynamic carve in
HyperFrames does the rest.

LUFS-I of very short one-shots is indicative only.
