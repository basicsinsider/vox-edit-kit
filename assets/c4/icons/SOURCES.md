# assets/c4/icons — c4 isotype pictogram family (made by the c4s02 editor, 2026-10-31; own work, no licence issues)
Filled ink silhouettes in a 100×100 box (ref D03 isotype). Same shapes are inlined in `compositions/c4s02.html` (const PICTO) so
they can be coloured/animated; c4s03 reuses them (graduates, generals, engineers → derive from `person.svg`).

| farmer.svg | tenant farmer / producers (C4S051–052, C4S059) |
| landowner.svg | landowner / manager (C4S051–052, C4S055, C4S059) |
| industrialist.svg | industrialist (C4S059) |
| factory.svg | state-owned company (C4S055, C4S059) |
| coin.svg | profit (C4S058) |
| bulb.svg | electric grid (C4S044, line icon) |
