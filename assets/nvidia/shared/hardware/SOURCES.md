## Notes for editors
- **A800 / H800**: China-market versions of A100 / H100 (lower interconnect bandwidth) — physically the same SXM boards / PCIe cards; NVIDIA published no separate photos. Use the A100 / H100 images (label them A800 / H800 on screen).
- **H20**: also a Hopper SXM board (HGX H20), visually identical to the H100 SXM — no distinct public product photo found; use h100_sxm_* with an "H20" label.
- **RTX 4090 D** box: not found (no free/press image reachable). **Retail boxed RTX card on a shop shelf**: not found on Commons; nearest = HK Golden Computer Arcade / Wan Chai stalls in places/.
- **Huawei Ascend 910B/910C chip**: no photo found (huawei.com news page answered 503; Commons has none) — use huawei_atlas900_superpod_* (Atlas 900 A3 SuperPoD = 384 Ascend chips, WAIC 2025) and the chip icon.
- **Rack side view**: no clean side view found; vera_rubin_racks_jensen_stage.jpg (a person beside a row of racks, 6374 px) shows the fridge-size scale; nvidia_hgx_b200_tray_photo.jpg / gb300 renders for detail.
- **Barcode/serial sticker on a server**: not found (only unrelated/sensitive images) — use icons/barcode_label.svg.
- xai_colossus_* / liquid_cooling_* (ServeTheHome) are only ~1200 px: use as panels/cards, not full-frame pushes.
- 1990s export-control supercomputer: cray_ymp_1988_gsfc.jpg (Cray Y-MP, the late-80s/90s class) and cray_1_1976.jpg; mushroom clouds: Trinity 1945 (grainy B/W) and Castle Bravo 1954 (colour, 1280 px).
- rtx4090_fe_press.png / rtx4090_fe_box_1.jpg = the RTX 4090 gaming card; rtx4090_pcb_ad102.jpg + gpu_die_ad102_closeup.jpg = bare board + chip close-up.
