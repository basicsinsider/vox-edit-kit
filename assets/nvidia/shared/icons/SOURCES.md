# assets/nvidia/shared/icons — own work (CC0), asset gatherer C, 2026-11-17
24 flat single-colour pictograms drawn by hand as SVG (generator: work/nv-gatherC/icons.py, not committed). Same family rules as
`assets/c4/icons/` (filled isotype silhouettes) — 256×256 viewBox, `fill="currentColor"` (colour via CSS `color`), two weights:
solid silhouette + 16 px knock-outs / 8 px fine details. Rendered in headless Chrome and checked: `_sheet.jpg` (ink / vermilion).
