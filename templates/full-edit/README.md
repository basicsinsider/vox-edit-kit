# The approved 10-minute edit — source code (worked examples)

seg01–seg06 are the six segments of the approved edit (0–600 s of vo10.mp3). Watch the result in
`expected/final_edit_720p.mp4`; stills of each reference layout are in `expected/layouts/`.
They are here to READ and copy techniques from: most of their archival media is not in the repo (≈2 GB). Every file
they use is listed with its exact source URL in `example-docs/sources/`, so any piece can be re-downloaded
(`tools/find_media.py`, `tools/commons_thumb.sh`) if you want to re-render a segment.
`generators/seg01`, `generators/seg03` inline map paths into their templates (edit the template, then run the generator).
`segNN.NOTES.md` = what each editor built and why; `segNN.sfx.json` = the per-object sound markers.
