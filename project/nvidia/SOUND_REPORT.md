## What phase 2 changed
- **Missing library SFX**: the box held only the 29 NVIDIA SFX; place_sound's Epidemic renders for the editors' existing types need
  25 older files (paper slides, whooshes, stamps, keyboard, factory hum, walla …) → re-downloaded by id (LOG.md "NVIDIA phase-2").
- **Per-act trims** (`TRIM` in make_cuesheet.py): the untrimmed whole-length build measured N1–N10 −22.7…−24.0 but N11–N20
  −24.3…−28.8 (N13 −27.8, N17 −28.8). The bed normalisation is global and the duck caps the loud acts, so trims were estimated
  with the real music pipeline per candidate (`work/nv-sound/scripts/est_trims.py`, 4 candidates, music bed only) and then one
  real build: up for the quiet un-ducked acts (N11 +4, N12 +1.5, N13 +7, N14 +3.5, N15 +3, N16 +2, N17 +8, N18 +5.5, N19 +2.5,
  N20 +4, N5 +1.5), slightly down for the duck-limited acts (N6 −1, N7 −1.5, N9 −1.5, N10 −1) — lowering those frees normalisation
  headroom while the duck backs off. Every act now −23.7…−25.1 LU; the whole bed sits at −24.7 (the binding 22 LU target + the
  duck's ≈ 2.5 dB do not allow −24 everywhere without loosening a limit; quieter is the accepted side).
- **Music 3 s minimum**: two VO-quiet slivers the duck can't catch (342.5 "bad things with AI", VO −41.6 LUFS-S; 1230.6) → cue-sheet
  dips: N5 Subconscious −8 dB 340–344.5, N13 Cinema Neon's −2 dB dip now from 1228.
- **music+SFX ≥ 14 LU**: the first build failed (min 4.2 LU at 2286, ~25 spans < 14 LU: sustained ticks/scribbles/whooshes in the
  quiet passages of a quiet VO). New cue-sheet key **`sfx_limit: {gap: 14, margin: 1}`** → `epidemic_bed.sfx_limit()` (called by
  place_sound before sfx.wav is written): a gain rider on the SFX bus only, measured exactly as vo_music_scan.py does (K-weighted
  3 s windows, speaking = VO 3 s > VO_LUFS − 12). SFX bus cut 5.05 % of the time, mean −3.3 dB while cut, max −12.8 dB.
- `tools/audio/measure_mix.py`: the SFX-peak section crashed when the beds run past the VO (2402.0 vs 2400.62 s) → compares the
  common span. `.gitignore`: `assets/audio/nvidia/*.wav` added.
