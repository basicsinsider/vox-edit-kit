# c3s02 — NOTES (chunk c3, LOCAL VO 200.34–404.17, C3S043–C3S077)

Built 2026-10-31 by the c3s02 segment editor. Lint: 0 errors for c3s02 (sandbox `work/c3s02`; only the usual
`nested_media_start_basis_ambiguous` warnings, data-starts are composition-local). `sync_audit`: 0 flagged — every text cue is a
literal `T(word − 0.06)`; the seven "+0.02" lines are the −0.06 cue of the next word matched to a short neighbour ('a'/'the').
Every scene snapshotted (start / middle / end) and fixed. Not rendered (lead renders).

## Source of truth / how to edit
`compositions/c3s02.html` is **generated**: edit `project/c3/gen/c3s02.src.html` (markup + CSS) and
`project/c3/gen/c3s02.scenes_{a,b,c}.js` (timeline), then `python3 project/c3/gen/build_c3s02.py` (inlines
`assets/c3/derived/c3s02/c3s02_maps.json`). Derived assets: `.venv/bin/python project/c3/gen/c3s02_assets.py` (needs the Esri z9
tiles: `.venv/bin/python tools/map_tiles.py fetch esri 9 115.5 20.4 125.6 27.6` first — cache was deleted to save disk).
